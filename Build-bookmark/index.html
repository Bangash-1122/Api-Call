Markdown Syntax Guide

Headings

# Heading 1
## Heading 2
### Heading 3
<h1>Heading 1</h1>

Bold Text

**bold text** or __bold text__
<strong>bold text</strong>

Italic Text

*italic text* or _italic text_
<em>italic text</em>

Links

[link text](URL)
<a href="URL">link text</a>

Images

![alt text](image URL)
<img alt="alt text" src="image URL">

Blockquotes

> quoted text
<blockquote>quoted text</blockquote>
